# Project Description

## Overview

A small Python program used to practice Git commands like commit, branch, merge and push.

## Features

- Prints my name and today's date
- Calculator functions in `src/utils.py`:
  - `add(a, b)`
  - `subtract(a, b)`
  - `multiply(a, b)`
  - `divide(a, b)`

## Git Workflow Practiced

- Initializing a repository with `git init`
- Making commits with clear messages
- Creating feature branches (`feature/calculator`, `feature/error-handling`)
- Merging branches into `main` with `--no-ff`
- Pushing to GitHub
